Colour

Brand colours are exact. Two derived tokens exist only for accessibility: brand gold is 2.5:1 on ivory, so gold-toned text uses --gold-text; warm grey is 4.4:1 on ivory, so small secondary text uses --grey-text.

Three layers, three animations

Entrance runs on the outer layer, the float on the middle layer and the pointer tilt on the inner layer, so none of them writes to the same element's transform. On touch screens the quick controls sit behind the + button and are never hover-only. Reduced-motion users get static cards.
